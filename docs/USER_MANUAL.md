# church-partner-hub 사용자 매뉴얼 (User Manual)

**church-partner-hub**는 교회 협력 사역 담당자를 위한 **이원화 엑셀 관리, 2단계 주소·홈페이지 그라운딩, 공문/선물 퀵서처, 교세 분석 대시보드, 옵시디언 볼트 스마트 동기화**를 통합 제공하는 데스크톱 전용 도구입니다.

---

## 1. 시스템 요구사항 및 시작하기

### 1.1 요구 환경
- **운영체제**: Windows 10 / 11 (64-bit)
- **런타임**: Microsoft Edge WebView2 (Windows 10/11 기본 탑재)
- **개발 환경(소스 실행 시)**: Python 3.10 이상

### 1.2 소스코드 실행 방법
```powershell
# 가상환경 활성화 후 의존성 설치
pip install -r requirements.txt

# 데스크톱 애플리케이션 실행
python src/main.py

# 무결성 검증 (스모크 테스트)
python src/main.py --smoke-test

# 전체 단위 테스트 실행 (55종)
python -m pytest -v
```

### 1.3 포터블 `.exe` 단일 실행 파일 빌드 방법
사용자가 별도의 파이썬 설치 없이 실행할 수 있는 무설치 포터블 단일 파일(`dist/church-partner-hub.exe`)을 빌드할 수 있습니다.
```powershell
# 원클릭 빌드 배치 파일 실행
.\scripts\build_exe.bat

# 또는 파이썬 스크립트로 빌드
python scripts/build_exe.py
```
> 빌드가 완료되면 `dist/church-partner-hub.exe` 파일이 생성됩니다.

## 2. 작업 모드 (Dual-Mode Architecture)

상단 헤더 중앙의 토글 버튼을 통해 작업 목적에 맞는 모드를 원클릭으로 전환할 수 있습니다.

```
┌─────────────────────────────────┐
│ [ 마스터 관리 모드 ]  [ 간편 주소록 모드 ] │
└─────────────────────────────────┘
```

1. **마스터 관리 모드 (내부 기획자용)**:
   - 17개 고유 사역 관리 컬럼(온도감, 관리유형, 제안사업 등) 보존
   - 부가 컬럼(`우편번호`, `홈페이지`, `주소검증상태`, `홈페이지검증상태`, `Obsidian링크`) 자동 관리
   - 교세 분석 대시보드 및 옵시디언 동기화 탭 활성화
2. **간편 주소록 모드 (타 부서 및 외부 협력자용)**:
   - 3개 필수 헤더 `[담임목사, 지역, 교회명]` 입력 ➡️ 7개 표준 헤더 `[교회명, 담임목사, 지역, 도로명 주소, 우편번호, 교회 홈페이지, 검증 상태]` 정제 출력
   - 복잡한 사역 컬럼 없이 대량 주소 정제에 최적화

## 3. 핵심 기능별 상세 가이드

### 3.1 대시보드 (Dashboard)
- **KPI 통계**: 총 등록 교회, 도로명 주소 완료 건수, 공식 홈페이지 완료 건수 실시간 집계
- **엑셀 열기 / 저장**:
  - `📂 엑셀 파일 열기`: 구글 스프레드시트 내보내기 파일 또는 일반 엑셀 파일 로드
  - `💾 엑셀 저장`: 원본 서식/수식 보존 및 원자적 교체(`os.replace`)로 파일 잠금 방지
  - `📤 간편 주소록 내보내기`: 정제된 주소록 파일 다운로드

### 3.2 2단계 주소 & 홈페이지 연계 검증 (Grounding)
- **1단계: 도로명 주소 탐색**:
  - 카카오/네이버 지도 검색을 결합하여 후보 도로명 주소와 우편번호 탐색
  - 신뢰도 점수 산출: 🟢 High (90%+), 🟡 Medium (70~89%), 🔴 Low (<70%)
- **2단계: 홈페이지 교차 검증 & 종속적 불확실성 (Cascading Uncertainty)**:
  - **불변식 규칙**: 1차 대상인 주소가 '미검증' 또는 '불확실' 상태일 경우, 연결된 홈페이지 역시 자동으로 **`불확실(주소불확실종속)`** 배지가 부여되며 승인이 보류됩니다.
  - 사용자가 도로명 주소를 [승인]하거나 수기 입력 완료 시, 홈페이지 신뢰도가 즉시 재평가됩니다.
- **원클릭 액션**: `[승인]`, `[주소/URL 수기 수정]`, `[네이버/카카오 지도 바로가기]`

### 3.3 공문/선물 발송 퀵서처 (Quick Dispatcher)
- **실시간 검색**:
  - **초성 검색 지원**: `ㄱㅈㅅ` 입력 시 ➡️ `광주겨자씨교회` 즉시 필터링
  - 담임목사 성함 검색 지원
- **원클릭 클립보드 복사**:
  - **공문용**: `수신: 광주겨자씨교회 (나학수 목사 귀하) / 주소: (61645) 광주광역시 남구 봉선로 12`
  - **택배/선물용**: `광주겨자씨교회 / 나학수 / 광주광역시 남구 봉선로 12 / 61645`
  - **스프레드시트용 (TSV)**: 엑셀에 바로 `Ctrl+V` 가능한 탭 구분 형식
- **발송 명단 엑셀 다운로드**: 현재 검색되거나 선택된 명단을 엑셀 파일로 즉시 출력

### 3.4 지역별 교세·교단·규모 분석 대시보드 (Regional Analytics)
- **4대 요약 통계 카드**: 총 교회 수, 총 성도 수 합산, 평균 성도 수(최대/최소), 성도 수 입력률
- **교단별 & 5단계 규모별 반응형 막대 차트**:
  - 🟢 **소형 교회**: ~100명 미만
  - 🔵 **중형 교회**: 100명 ~ 500명 미만
  - 🟡 **중대형 교회**: 500명 ~ 1,000명 미만
  - 🟠 **대형 교회**: 1,000명 ~ 3,000명 미만
  - 🔴 **초대형 교회**: 3,000명 이상
  - ⚪ 성도 수 미입력 카테고리
  - 막대 클릭 시 해당 교단 또는 규모 조건으로 즉시 필터링
- **교단 × 5단계 규모 교차 집계표 (Cross-tabulation Matrix)**:
  - 행(교단)과 열(규모)이 교차하는 셀 클릭 시 해당 조건의 교회가 하단에 실시간 **드릴다운(Drill-down)**
- **드릴다운 교회 목록**:
  - 적용된 필터 알약(Chip) 표시 및 개별 원클릭 해제
  - No, 교회명, 담임목사, 교단, 규모 세그먼트, 관리 등급, 주소, 원클릭 복사 제공

### 3.5 옵시디언 스마트 동기화 스튜디오 (Obsidian Studio)
- **볼트 자동 인식**:
  - 기본 볼트 경로(`C:\Users\20260602\Documents\github\Obsidian`) 내 `20. Churches` 및 `90. Templates` 자동 감지
  - 환경 설정 탭에서 볼트 경로 자유롭게 변경 가능
- **정보 불일치 대조 & 상호 해결 (Diff Resolution)**:
  - 엑셀과 볼트 간 담임목사, 교단, 지역, 등급 차이점을 실시간 감지
  - `[엑셀 기준 적용 ➡️]`: 옵시디언 마크다운의 YAML Frontmatter를 엑셀 값으로 안전하게 갱신 (본문 Dataview 쿼리는 단 1글자도 훼손되지 않음)
  - `[⬅️ 옵시디언 기준 적용]`: 옵시디언 볼트의 값으로 엑셀 마스터 행 필드를 즉시 갱신
- **양방향 상호 보완 (Gap-fill)**:
  - **엑셀 ➡️ 볼트**: 엑셀에는 있으나 볼트에 없는 교회를 `Template - Church (교회_조직).md` 양식으로 자동 생성 (개별 생성 및 `[⚡ 전체 일괄 자동 생성]`)
  - **볼트 ➡️ 엑셀**: 볼트에는 있으나 엑셀에 없는 교회를 원클릭으로 엑셀 새 행으로 가져오기 (`[📥 엑셀로 가져오기]`)
- **Obsidian 딥링크 연동**:
  - `🔗 옵시디언 열기` 클릭 시 데스크톱에 설치된 옵시디언 앱에서 해당 교회 노트가 즉시 오픈 (`obsidian://open?...`)

## 4. 기술 안전 및 데이터 보호 원칙

1. **엑셀 원본 서식/수식 100% 보존**:
   - 기존 열의 폰트, 테두리, 배경색, 수식을 절대 손상하지 않습니다.
2. **옵시디언 마크다운 본문 보존 (Raw Preserve)**:
   - YAML Frontmatter만 안전하게 분리/치환하며, 본문의 Dataview 스크립트나 작성 메모를 그대로 보존합니다.
3. **SSRF 및 악의적 웹 요청 차단**:
   - 비공개 IP(`127.0.0.1`, `10.x`, `192.168.x`), 메타데이터 엔드포인트(`169.254.169.254`), 파일 스킴(`file://`) 접근을 원천 차단합니다.
4. **DoS 방지 및 메모리 보호**:
   - 외부 웹페이지 수집 시 응답 본문 크기를 최대 2MB로 제한하고, 5초 타임아웃을 강제합니다.
5. **DOM XSS 방지**:
   - 프론트엔드에 렌더링되는 모든 사용자 입력 및 외부 데이터는 엄격한 HTML 이스케이프(`escapeHtml`)를 거칩니다.
